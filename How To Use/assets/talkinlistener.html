Introduction

Hey there, This is for Talkin app documentation to know the app in better way and how to use it.

Home

  • Activate Earnings: Toggle *"Get 20 Coin/Min"* to start earning during random support calls.
  • Permission Alert: Ensure "Allow Random Call" is enabled to receive connections.
  • Safety First: Never share passwords, OTP codes, or private details with callers (scam warning shown).

Notification

  • View Updates: Check timestamps to track recent activity - calls appear first, followed by messages (text/image).

Recent Calling

  • Review Activity: See all missed/received calls with timestamps.
  • Quick Reconnect: Tap "Talk Now" to instantly call back any recent contact.
  • Call Options: Choose Audio Call or Video Call when initiating new conversations.

Chat Details

Chat Screen

  • View all recent conversations sorted by date/time.
  • Tap any user (e.g., Jems bond) to open chat history.

Personal Chat

  • Send text messages in "Type Something..." box.
  • Make Audio/Video calls using call button.
  • View entire message history with timestamps.

Wallet Details

  • Check Balance & Earnings:View your Current Coin Balance.

Withdraw

  • Enter Coin Amount:Type the number of coins to withdraw.
  • Select Payment Method:Choose your preferred payment gateway (e.g., UPI, PayPal).
  • Confirm Withdrawal:Tap "Withdraw Coin" to submit request ,Ensure your payment details are verified.

View History

  • coin history: View coins earned per call with timestamps,Filter by date using "Select Date" option.
  • withdwaw history : Check Withdrawal ID, Status (Pending/Completed),See Payment Method and Request Date details.

Profile Details

  • View profile details (name/email),Access Settings or Help Center,Share app or review Privacy/About Us.

Edit Profile

  • Enter your Name, Nickname (e.g., "baby doll 🌟"), and Introduction.
  • Tap "SAVED" to confirm changes.

Help Center

  • Browse FAQs: Tap any question (e.g., "How do I become a User?") to view instant answers.
  • Contact Support: Select "Have an Issue?" to email the support team for unresolved queries.

Setting

  • Customize Preferences: Toggle options like APP Language or Notifications for personalized experience.
  • Account Actions: Select Logout or Delete Account (confirm carefully as deletion is permanent).

Language

  • Select Preferred Language: Choose from the list (e.g., English, Hindi, etc.) to change app language instantly.
  • Auto-Apply: Selected language updates all app text/settings immediately.
