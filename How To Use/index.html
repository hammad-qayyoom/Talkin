Introduction

Hey there, This is documentation for admin to know the functionalities in better way for the admin panel by author.

Dashboard

  • This dashboard shows an overview of user and listener statistics, a graph of user and listener overview, and a table listing recent users with their details.

User Details

  • Displays a searchable, paginated list of users showing key info like email, country, coin balance, online status, and block/unblock options.
  • Admin can view each user's profile along with Coin transaction history, Call activity log, Coin plan purchase history

Listener Details

  • Shows a searchable, paginated list of all listener with key details like name, call rate, earnings (coins), age, and call count.
  • Admin can add, update, or delete listeners. Additionally, they can toggle each listener between fake and real status.
  • Admin can view each listener's profile along with Coin transaction history, Call activity log.

Listener Request Details

  • Admin can view and manage listener requests, including user info, listener details, and current request status.
  • Requests can be toggled between Pending, Accepted, and Declined statuses.
  • Admin can also accept or decline requests, with the option to provide a reason.

FAQs Details

  • Admin can view and manage FAQs for both users and listeners, including the question and corresponding answer details.

Talks Topics

  • Admin can add new talk topics, view existing ones, and edit or delete them as needed.
  • These topics are used when users create requests for listeners.

Identity proofs

  • Admin can view and manage identity proof types, which are required when users submit listener requests.

Plan Details

  • Admin can create new plans, view existing ones, and manage their status by activating or deactivating them.

Plan History

  • Admin can view which listener purchased which plan, along with the payment gateway used for the transaction.

Payment Option

  • Admin can add new payment options and toggle them on or off. These options are used when listeners request withdrawals.

Payout Request

  • Admin can view all Pending, Accepted, and Declined redeem requests.
  • Admin have the authority to approve valid requests or decline inappropriate ones.
  • Redeem requests are withdrawal requests submitted by listeners.

Setting

  • This is a crucial section where the admin can configure and manage key application settings.
  • Admin can update settings such as fake data toggles, call rates, Firebase configuration, Zego integration, and login bonus parameters.
  • Admin manages important links like privacy policies for users and listeners, about pages, and support email addresses.
  • Admin can update payment credentials and secret keys for providers like RazorPay, Stripe, and Flutterwave.
  • Admin can toggle payment gateways between active and inactive statuses as needed.
  • Admin can manage multiple currencies and set a default currency for the platform.
  • Admin can set the coin ratio and manage the minimum coin payout thresholds for listeners.

Profile

  • Admin can update their own profile details, including profile photo, password, and name.
